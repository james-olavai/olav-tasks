# 独立 npm 工程与开发入口

## 目标

建立可独立构建的 Node CLI、本地服务和 React 网页工程。

## 范围

- 确认 Node 最低支持版本；使用 TypeScript，开发网页使用 Vite。
- 建立 package.json、CLI bin、构建与开发入口、最小页面及版本输出。
- 启动时通过显式参数选择项目根目录；默认本地监听，支持端口冲突提示与正常退出。

## 验收条件

- 全新目录安装依赖后，文档中的开发和构建命令可执行。
- CLI 帮助与版本可用；缺目录和无效目录返回可理解的错误。
- 运行不导入 olav-os 的服务、私有模块或本机参考克隆。
