# npm 包安装与启动验收

## 目标

将网页、本地服务、CLI 与 skills 封装为可独立安装的 npm 包。

## 范围

- 配置 bin、files、engines 与构建产物；发布候选名称先核实可用性。
- 提供准确的安装、启动、项目路径、端口、skills 安装和卸载说明。
- 使用 npm pack 生成本地 tarball，在隔离临时目录安装并验收。
- 检查静态资源、skills 和署名随包齐全，开发缓存与私有配置不进入包。

## 验收条件

- 从本地 tarball 安装后能启动，界面与文件操作可用，不依赖源仓库。
- skills 可从安装后的包复制到指定目标，npm 卸载可移除 CLI。
- README 命令来自实际验证，未公开发布时明确是本地安装验收。
- 记录 tarball 清单和验证结果；对外 npm 发布需另行取得授权。
