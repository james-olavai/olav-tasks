# 为团队协作任务加入负责人、工作量和模型档位

## 目标

让 Markdown 任务记录谁负责、工作量大小，以及需要 subagent 时适合使用的模型档位。

## 范围

- 增加可选 frontmatter 字段 `assignee`、`effort`、`model_profile`，兼容无这些字段的旧任务。
- Backlog 和 Kanban 显示协作元数据；普通任务状态仍由 Agent 修改 Markdown。
- 规划与写 Markdown skills 遵守“不猜负责人/估算/模型”的约定；模型档位通过项目 AGENTS.md 映射到可用模型。

## 依赖

依赖 OT-003 任务解析、OT-006 Kanban、OT-008 Markdown 写入 skill、OT-015 规划 skill。

## 验收条件

- 字段校验和旧任务兼容通过；页面显示负责人、工作量与模型档位。
- 相关 skills、README 与任务格式契约同步更新。
- olav-tasks 类型检查与构建通过；浏览器核验 Backlog、看板与窄屏布局。

## 实施结果

完成可选字段解析和校验、Backlog/Kanban 元数据只读展示、旧任务兼容，并更新 README、任务格式文档及规划/写入 skills。`npm run typecheck`、`npm run build` 通过；浏览器窄屏验收与解析边界检查记录在 Olav OS `dev_docs/06-local-tasks-acceptance.md`。
