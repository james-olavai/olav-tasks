# 外部文件变化与冲突恢复

## 目标

让编辑器和 Agent 的本地修改及时反映到界面，并保护未保存内容。

## 范围

- 选择适用于目标 Node 版本的平台监听方案，覆盖创建、修改、移动与删除。
- 实现网页更新通知或等效机制，抑制重复刷新并在断连后重新读取。
- 外部更新时刷新预览与卡片；有未保存编辑时保留用户输入并提示冲突。
- 服务退出释放监听与连接，不在项目目录生成隐藏权威副本。

## 验收条件

- 外部改状态、正文、新增与删除文件，界面无需手动重启即可更新。
- Agent 更新与网页编辑交错时冲突可恢复，没有静默丢失编辑。
- 断连重连能读取最新文件，删除当前打开文件有明确提示。
