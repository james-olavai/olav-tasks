# 整理 Markdown skill

## 目标

让 Agent 梳理本地项目文档和进度，形成可浏览的索引。

## 范围

- 创建 olav-tasks-organize-markdown/SKILL.md，先读取项目已有规则、目录与文档引用。
- 复用配套 docs-kb 搜索与长文定位，先找到实际内容再维护索引；不重新实现一套独立检索规则。
- 默认通过新增或更新索引、补充用户需要的任务入口来整理，不批量搬移既有资料。
- 需要移动或重命名时列出范围和引用影响，按用户授权执行并报告检查范围。
- 任务状态只根据实际执行证据更新；不把未知进度写成完成，不复制平行任务记录。

## 验收条件

- skill 格式有效，遵循同一任务契约，能够整理本项目 backlog 索引。
- 真实项目整理后索引链接可用，原有 Markdown 内容及规范未被自动重写。
- 整理结果说明新增/修改文件和未解决引用，不虚报全仓链接修复。
