# 文件树、Markdown 预览与编辑

## 目标

让用户在浏览器里管理现有项目文件和阅读 Markdown。

## 范围

- 实现目录树、文件选择、Markdown 预览和编辑保存。
- 支持新建、重命名、移动与删除确认；未保存编辑离开前提示。
- 支持标题、列表、代码块、表格、任务列表以及项目内相对链接和图片；禁用未经处理的可执行 HTML。
- 普通非 Markdown 文件在目录中可见，明确显示受支持的预览类型与不支持提示。

## 验收条件

- 选择任意现有 Markdown 即可预览，任务 frontmatter 不作为正文展示。
- 新建和编辑结果实际落盘，重新打开可读回；移动与重命名后选择状态正确。
- 删除需确认；失败保留原界面与输入；图标操作具备可访问名称。
- 相对链接在项目边界内打开；恶意文档不能在预览中执行脚本。
