# Kanban 与拖动状态更新

## 目标

以待办、进行中、完成三列展示本地 Markdown 任务。

## 范围

- 从服务端读取有效任务，列按 status 映射，显示标题与已有优先级。
- 点击卡片打开对应 Markdown 预览，保留与文件树的选择关联。
- 拖动或键盘/菜单操作只迁移状态；失败回滚并显示原因。
- 普通 Markdown 不显示为任务；无任务与无效文件分别提供可理解的状态。

## 验收条件

- 本项目 backlog 的每个有效任务恰好一张卡片，归入正确列。
- 改变列后实际文件 status 更新，正文不变；重启后卡片仍在目标列。
- 网络失败、版本冲突和文件被删除时不残留虚假的成功状态。
- 无需拖动也能通过可访问操作改变状态；窄屏仍可查看与打开卡片。
