# skills 安装入口

## 目标

让同一个 npm 包提供可被 Agent 发现的规划、编写、整理和 docs-kb 四个 skills。

## 范围

- 明确首个支持的 Agent 发现目录，优先核实 Codex；支持用户显式指定安装目标。
- CLI 提供列出内置 skills、显示目标和执行安装的入口；npm 安装不自动修改 Agent 配置。
- 安装复制完整 skill 目录；已有不同内容时提示冲突，重复安装不破坏用户修改。
- 卸载只处理本工具安装且未被用户修改的文件；说明升级与覆盖行为。

## 验收条件

- 包安装后四个 skill 文件及必要检索资源实际存在，安装命令使支持的 Agent 能发现它们；安装目录中的脚本或 CLI 引用在 npm 升级、移动安装目标后仍需有明确可用性规则。
- 没有安装目标或路径无效时给出准确说明；没有隐式修改全局配置的 postinstall。
- 重复安装及已有用户修改场景不静默覆盖；列出安装路径与结果。
